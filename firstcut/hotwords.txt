# 领域热词（ASR 解码提示 / initial_prompt）
# 用途：把领域内的专有名词与术语喂给 whisper 解码器，显著降低专名错字率。
#       改这个文件即可，无需改代码；留空或不建此文件 = 不注入（保持原行为）。
#
# 经验（实测对照）：
#   · 提示"短而准"最好 —— 只给「人名 + 核心术语」；提示写成一整段话时，
#     whisper 会把整片"改写"成一段连续文本，虽然专名全对，但偶发漏字（实测漏掉"记得"）。
#   · 无论提示长短，只要注入了提示，whisper 就会把整片合并成 1 个句段。
#     因此提示只用于「成片字幕」这一步；转写原片做重说检测时必须关掉
#     （run.mjs 已自动传 XUNJIAN_ASR_HOTWORDS=off）。
#   · 提示没纠正到的个别错字，由 asr_and_caps.py 里的 FIXES 词典兜底。
